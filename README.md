# KGM2MP3

一键式音频格式转换工具（Windows 本地版），专为小白设计：双击启动、图形界面、勾选即转。

> 原名 OneClick-KugouMP3-Pack，现名 **KGM2MP3**。

## 它能做什么

把以下格式**批量**转换为 MP3 / WAV / FLAC / M4A / OGG / OPUS / WMA：

- 酷狗加密格式：`kgg` / `kgm` / `kgma`
- 网易云加密格式：`ncm`
- 常见格式：`mp3` / `wav` / `aac` / `m4a` / `flac` / `ogg` / `wma` / `opus`

MP3 输出提供三档质量：**高质量（默认）/ 标准 / 省空间**。

## 快速开始（4 步）

1. 双击 `启动转换器.bat`
2. 点击「选择文件」，选中要转换的文件（可多选）
3. 选择输出格式（默认 MP3），如选 MP3 可再选质量档位
4. 点击「开始转换」

完成后，成品在 `output` 文件夹，日志在 `logs` 文件夹。

## 特点

- **纯本地运行**：所有转换都在本机完成，不上传任何文件
- **免安装**：常用工具已内置在 `tools` 文件夹，双击即用
- **自动检测**：缺工具会给出可理解的提示，不会莫名报错
- **面向小白**：界面和提示均使用大白话，无专业术语门槛

## 目录结构

```
├─ 启动转换器.bat      # 一键启动入口
├─ app.ps1             # 主程序（PowerShell + WinForms）
├─ input/              # 输入文件（可把要转的文件放这里）
├─ output/             # 转换后的成品
├─ logs/               # 转换日志
├─ tools/              # 内置工具（见下方说明）
└─ ui/                 # 网页版界面（实验性，非主入口）
```

## 常见问题

- **kgg 提示 ekey not found？** 说明本机没有该歌曲的解密 key，在酷狗客户端里登录并重新下载这首歌后再试。
- **OGG / OPUS 播放器放不了？** 部分播放器兼容性一般，优先导出 MP3。
- **WMA 是给谁的？** 偏 Windows 环境，其他平台请选 MP3。
