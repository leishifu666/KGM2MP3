【OneClick-KugouMP3-Pack｜小白使用说明】

你只需要做 4 步：

1、双击：启动转换器.bat
2、在窗口里点“选择文件”
3、选中 kgg / kgm / kgma / ncm / mp3 / wav / aac / m4a / flac / ogg / wma / opus 文件
4、按需要选择输出格式（MP3 / WAV / FLAC / M4A / OGG / OPUS / WMA）
5、如果输出格式是 MP3，可再选择“高质量 / 标准 / 省空间”
6、点“开始转换”

完成后：
- 所选格式成品在 output 文件夹
- 日志在 logs 文件夹

说明：
- 常用工具已经内置在 tools 文件夹
- 如果缺少某些工具，会自动检测
- kgm / kgma 通常更容易直接转换
- ncm 需要 tools 目录中有 ncmdump.exe
- 质量档位仅对 MP3 输出生效，其他格式使用固定参数导出
- OGG / OPUS 在部分播放器兼容性一般，WMA 更偏向 Windows 环境；如遇播放问题，可优先导出 MP3
- kgg 是否能成功转换，取决于当前电脑有没有对应 key
- 如果 kgg 提示 ekey not found，请在本机酷狗里登录并重新下载这首歌后再试
