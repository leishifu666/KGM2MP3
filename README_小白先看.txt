【OneClick-KugouMP3-Pack｜小白使用说明】

你只需要做 4 步：

1、双击：启动转换器.bat
2、在窗口里点“选择文件”
3、选中 kgg / kgm / kgma / flac 文件
4、点“开始转换”

完成后：
- mp3 成品在 output 文件夹
- 日志在 logs 文件夹

说明：
- 常用工具已经内置在 tools 文件夹
- 如果缺少某些工具，会自动检测
- kgm / kgma 通常更容易直接转换
- kgg 是否能成功转换，取决于当前电脑有没有对应 key
- 如果 kgg 提示 ekey not found，请在本机酷狗里登录并重新下载这首歌后再试
